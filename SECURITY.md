# Security Policy

## Reporting a problem

Please report security or privacy concerns privately by email to [ai-research-foundations@aims.ac.za](mailto:ai-research-foundations@aims.ac.za). Do not open a public issue.

Include:

- The file, notebook or dataset involved
- A description of the problem and how to reproduce it
- Any suggested fix

We will acknowledge your report and keep you informed as we investigate.

## What to report

- Personal or sensitive information found in a dataset
- Leaked credentials or access tokens in notebooks or code
- Code that could harm a learner's environment or data
- Content that breaks a dataset's licence or terms of use

## Good practice for learners

- Store your Hugging Face token in Google Colab Secrets as `HF_TOKEN`. Never paste tokens into notebook cells.
- Do not share notebooks that contain outputs with personal data.
